隐私政策

最后更新：2026年8月27日

wedding-tv.cn（以下简称“本网站”）尊重并保护用户隐私。本政策按照当前实际功能说明信息如何处理，并将尚未启用的统计和广告服务单独列为“启用后”事项。

当前状态（2026年8月27日）：网站页面不加载百度统计、Google Analytics 或 Google AdSense 广告投放脚本，也不运行本站自建的点击行为追踪接口。网站页面包含 google-adsense-account 发布商账户关联元标签，用于 AdSense 账户所有权验证；该元标签本身不发起广告请求，也不设置广告 Cookie。报价对比器、应急预案生成器等本地工具的输入保存在用户浏览器中，不由工具代码主动上传至本站服务器。

1. 收集的信息类型

a) 您主动提供的信息

  • 邮件沟通数据：当您通过邮箱提交反馈、纠错、合作建议或撤稿请求时，我们会收到您的邮箱地址以及您主动提供的内容。
  • 本地工具信息：部分工具会在当前浏览器保存新人名字、婚礼日期、报价或预案条件，用于恢复页面状态。除非具体工具明确说明需要联网生成，否则页面不会主动把这些本地输入发送到本站服务器。
  • 电子请帖数据：当您生成公开请帖链接时，姓名、日期、地点、问候语、故事、所选音乐以及已上传图片的引用会发送到本站接口并保存到 Cloudflare KV，以便通过链接展示请帖。任何获得链接的人都可能查看其中内容。
  • AI 功能输入：当您主动使用文案、故事、头像或海报生成功能时，页面会把完成该请求所需的文字或图片发送到本站接口，再由对应 AI 服务提供商处理。请勿提交身份证件、银行卡、详细住址或第三方不愿公开的信息。

b) 自动收集的信息

  • 托管与安全日志：网站通过 Cloudflare 提供访问与安全防护。托管和网络服务商可能处理 IP 地址、浏览器类型、访问时间、请求页面及安全事件，以传送内容、识别攻击和维持服务。
  • API 频次防护与配额控制：为防止自动化脚本恶意刷取及保护免费 AI 工具配额，当您请求 AI 生成接口时，系统会对您的 IP 地址进行加盐单向散列（不保存明文 IP），并在 Cloudflare KV 中保留最多 48 小时用于统计当日调用频次，过期自动清除。
  • 浏览器本地存储：工具可能使用 localStorage 保存表单状态。您可以通过工具的清空按钮或浏览器站点数据设置删除。
  • 当前未启用的统计与广告服务：截至本页更新日期，页面未加载百度统计、Google Analytics 或 Google AdSense 广告投放脚本，因此本站当前不会通过这些页面脚本设置对应的统计或广告 Cookie。账户关联元标签不等同于广告投放代码。

2. 如何使用您的信息

我们使用收集的信息用于以下目的：

  • 处理您的反馈、纠错、合作建议、撤稿请求或工具问题。
  • 改进网站功能、内容和用户体验。
  • 防止欺诈、滥用和安全威胁。
  • 提供用户主动请求的邮件回复。
  • 根据用户主动反馈和非个体化的托管运行信息改进页面性能与功能。

3. 数据共享与第三方

  • Cloudflare：用于托管、内容分发与安全防护，可能按其隐私政策处理网络请求数据。
  • 阿里云百炼 / DashScope：用于部分 AI 文案和海报生成。使用对应功能时，相关提示词和必要输入会发送给该服务。
  • Google Gemini：用于部分故事、图像理解和 AI 文案备用生成。使用对应功能时，相关文字或您主动上传的合照可能发送给该服务。
  • Cloudflare Workers AI：用于部分头像图像生成。头像功能会根据上一步形成的描述生成图片。
  • 二维码前端依赖：电子请帖和二维码海报会从 jsDelivr、unpkg 或 cdnjs 加载二维码生成库。浏览器请求这些静态脚本时，对应 CDN 可能按其规则处理 IP 地址、浏览器信息和本站来源域名；用户填入的二维码内容不会由页面代码主动发送给这些 CDN。
  • QR Server 故障回退：仅当电子请帖中的前端二维码库全部加载失败时，页面会把该公开请帖链接发送给 QR Server 生成二维码图片。请帖链接本身可被任何获得链接的人访问。
  • 百度统计、Google Analytics 和 AdSense：当前均未启用。未来启用任何一项服务时，本站将先更新本政策和必要的同意管理设置，再按实际配置说明数据用途、Cookie 和退出方式。
  • 邮件服务：仅在您主动发送邮件时，用于接收和回复。
  • 法律要求：如果法律要求或政府机构要求，我们可能会披露您的信息。

4. 数据保留

  • 邮件内容：在处理反馈、纠错或争议所需期间保留；您可以申请删除，但法律要求或争议留证需要保留的情况除外。
  • 浏览器本地数据：由您的浏览器保存，直到您使用工具清空、清除站点数据或浏览器按自身规则删除。
  • 电子请帖与上传图片：自 2026 年 8 月 11 日起新建的数据设置为创建后 365 天自动过期。此前创建的数据或需要提前删除的数据，可通过本页联系方式提交请帖链接申请处理。
  • AI 临时输入与生成结果：本站接口仅为完成当次请求向对应服务传输；第三方服务的日志、滥用监测和保存期限以其实际服务配置及隐私政策为准。
  • 托管与安全日志：保留期限由对应服务配置和提供商政策决定，本站不在本页承诺固定天数。
  • 已停用的本站点击追踪数据：相关公开接口已删除，部署后会自动清除此前保存在 Cloudflare KV 中、以 track: 开头的历史记录与汇总键。
  • 百度统计、Google Analytics 和 AdSense 数据：当前未通过页面脚本产生；启用后的保存和控制方式将按实际配置更新。
